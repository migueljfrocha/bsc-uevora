# Data Structures and Algorithms II

Problems developed for the Data Structures and Algorithms II course,
part of the Bachelor's Degree in Computer Science Engineering
at Universidade de Évora.

## Problems

| Problem | Description | Type |
|---------|-------------|------|
| [Problem&nbsp;1](./Problem-1/) | The Dream Factory, an optimization problem solved with dynamic programming. | Practical |
| [Problem&nbsp;2](./Problem-2/) | Palm Island Neighbours, a tree diameter problem solved with two breadth-first searches. | Practical |
| [Problem&nbsp;3](./Problem-3/) | Card Exchange, a bipartite matching problem modeled as maximum flow using Edmonds-Karp. | Practical |

## Main Topics

- Dynamic programming
- Graph traversal
- Tree diameter
- Bipartite matching
- Maximum flow
