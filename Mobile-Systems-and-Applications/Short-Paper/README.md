# Permission Misuse in Android Applications

A short paper about Android permission misuse and security risks, developed for the Mobile Systems and Applications course at Universidade de Évora.

## About

This paper analyzes the Android permission model and the security risks caused by permission misuse. It discusses over-privileged applications, API-to-permission mapping challenges, third-party libraries, permission piggybacking, and attacks that target the Android permission system.

The paper also covers Android's evolution from install-time permissions to runtime permissions and highlights mitigation mechanisms introduced across Android versions.

## Main Topics

- Android permission model
- Permission protection levels
- Runtime permissions
- Over-privileged applications
- Third-party libraries
- Permission piggybacking
- Component hijacking
- UI overlay attacks
