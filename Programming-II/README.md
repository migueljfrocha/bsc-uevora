# Palavra Guru - Word Puzzle Game

A Java implementation of a word puzzle game where players form words from given letters across multiple levels. Features both console and GUI interfaces, coin system, hints, and dictionary validation for the Programming II course at Universidade de Évora.

## About

This project implements "Palavra Guru", a word puzzle game where players must form all target words using a limited set of scrambled letters. The game includes a progression system with two different types of levels, a coin economy for hints, and dictionary validation for bonus words. There's also a save system to keep the progress of the last game played.

## Technologies

**Language:** Java 17+  
**GUI Framework:** Java Swing
