# Cross-Site Scripting - Impact and Mitigation

A theoretical article about Cross-Site Scripting (XSS), developed for the Security course at Universidade de Évora.

## About

This assignment studies **Cross-Site Scripting (XSS)** as a web application vulnerability where malicious scripts are injected into trusted websites and executed in victims' browsers.

The article explains the attack lifecycle, the main types of XSS, real-world impacts, and mitigation strategies. It also discusses preventive development practices and runtime defense mechanisms, emphasizing the need for layered security.

## Main Topics

- Cross-Site Scripting
- Stored XSS
- Reflected XSS
- DOM-based XSS
- Attack lifecycle
- Real-world security impact
- Input validation and sanitization
- Defense in depth
