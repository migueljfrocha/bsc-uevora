# XSS Attack Demonstration

An experimental security report about Cross-Site Scripting attacks, developed for the Security course at Universidade de Évora.

## About

This assignment demonstrates practical **Cross-Site Scripting (XSS)** attacks using the intentionally vulnerable **OWASP Juice Shop** application.

The work explores DOM-based XSS, reflected XSS, and stored XSS. It also demonstrates the practical impact of stored XSS through a chained scenario involving administrator session theft and reuse to publish malicious content.

An additional attempt was made to analyze the internship application with OWASP ZAP and manual testing, but no XSS vulnerability was identified, so the final demonstration focused on OWASP Juice Shop.

## Technologies and Tools Used

- OWASP Juice Shop
- Burp Suite
- Browser DevTools
- OWASP ZAP
