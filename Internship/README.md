# Full-Stack Development Internship - DigitalWorks

An internship report developed at **DigitalWorks by Plexus Tech** for the Internship Project course, part of the Bachelor's Degree in Computer Science Engineering at Universidade de Évora.

## About

This report documents the curricular internship carried out in a professional full-stack development environment. The work included training and small projects, followed by the development of a final web application project.

The internship covered backend and frontend development practices, application architecture, database persistence, authentication, and professional development workflows.

## Main Topics

- Full-stack web development
- C#, .NET, MVC, and REST APIs
- Umbraco CMS
- DataTables integration
- Domain-Driven Design
- SOLID principles
- Authentication and application security
