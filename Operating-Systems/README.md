# Operating Systems

Projects developed for the Operating Systems course,
part of the Bachelor's Degree in Computer Science Engineering
at Universidade de Évora.

## Projects

| Project | Description | Type |
|---------|-------------|------|
| [Project&nbsp;1](./Project-1/) | Process scheduling simulator based on the 5-state model and Round Robin scheduling. | Practical |

## Main Topics

- Process states
- Round Robin scheduling
- Virtual memory
- Page replacement
- Memory management
