# Partial-Order Planning

A Prolog assignment about automated planning with POP, developed for the Artificial Intelligence course at Universidade de Évora.

## About

This assignment models a planning problem using STRIPS-style actions and solves it with a **Partial-Order Planner (POP)**.

The work defines conditions, actions, initial and final states, causal links, ordering constraints, and threat resolution. The planner can output both a simple linearized plan and a detailed plan containing steps, order relations, and causal links.

## Technologies

**Language:** Prolog  
**Concepts:** Automated planning, STRIPS notation, partial-order planning, causal links, threat resolution

---

## How to Run

### Prerequisites

- A Prolog interpreter compatible with the predicates used in the assignment

### Steps

```prolog
[problema, pop].
plano(P).
```

For a more detailed result:

```prolog
plano_detalhado(Plano, Passos, Ordem, Links).
```
