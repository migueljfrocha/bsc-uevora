# Artificial Intelligence

Assignments developed for the Artificial Intelligence course,
part of the Bachelor's Degree in Computer Science Engineering
at Universidade de Évora.

## Assignments

| Assignment | Description | Type |
|------------|-------------|------|
| [Assignment&nbsp;1](./Assignment-1/) | State-space search problem in Prolog, using informed and uninformed strategies to move an agent and a machine through a grid. | Practical |
| [Assignment&nbsp;2](./Assignment-2/) | Constraint satisfaction problems, including Futoshiki and Latin Square solvers with backtracking and forward checking. | Practical |
| [Assignment&nbsp;3](./Assignment-3/) | Game-playing agent using minimax and alpha-beta pruning strategies. | Practical |
| [Assignment&nbsp;4](./Assignment-4/) | Automated planning problem modeled in Prolog, based on actions, preconditions, add lists, and delete lists. | Practical |

## Main Topics

- State-space representation
- Search algorithms
- Constraint satisfaction
- Adversarial search
- Automated planning
