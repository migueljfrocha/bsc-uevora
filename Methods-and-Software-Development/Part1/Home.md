# Eventastic v1.0

Bem-vindo à Wiki do projeto Eventastic. Este projeto visa desenvolver um sistema de *backend* para a gestão de eventos.

A aplicação de gestão de eventos tem como objetivo apoiar todo o processo de organização, inscrição e participação em atividades como conferências, *workshops*, encontros temáticos, entre outros.
