# Traffic Light Controller

A digital circuit design project developed for the **Digital Systems** course at Universidade de Évora.

## About

This project details the implementation of a **Synchronous Sequential Circuit** designed to control a system of two traffic lights, managing both vehicle and pedestrian traffic at a crossing. The system utilizes **Finite State Machines (FSM)** logic implemented with **T Flip-Flops** and logic gates.

The circuit ensures that traffic lights for vehicles and pedestrians do not conflict (lights are never Green simultaneously). A 7-segment display provides a synchronized countdown timer (8 to 1) for pedestrians.

## How to Run

### Prerequisites
- Circuit simulator ([Logisim-Evolution](https://github.com/logisim-evolution/logisim-evolution))
  
### Steps

**1. Load the `controlador_semaforos.circ` file.**  
**2. Enable Auto-Tick** (`Simulate -> Auto-Tick Enabled`) or manually toggle the clock to observe the sequence.
