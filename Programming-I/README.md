# Ouri - Board Game

A C implementation of the strategy board game "Ouri" where two players compete to collect stones through strategic sowing mechanics. Features a terminal interface, move validation, and capturing rules for the Programming I course at Universidade de Évora.

## About
This project is a simulation of the game "Ouri" ("Oware" in English). Ouri is a two-player game played on a board with twelve (12) houses, two (2) deposits, and forty-eight (48) stones. The goal is to collect more stones in your deposit than your opponent, with the winner being the first to accumulate twenty-five (25) or more stones.

## Technologies

**Language:** C  
**Build Tool:** Make
