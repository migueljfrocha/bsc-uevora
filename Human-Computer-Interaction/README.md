# HealtHub - Alentejo Revival

HealtHub is a project that simulates a "Unified Health Hub" application, developed for the **Human-Computer Interaction** course at Universidade de Évora.

## About

**HealtHub** is a centralized health management application designed to aggregate medical records, prescriptions, and appointments from disparate providers into a single environment.

The project development followed a structured lifecycle beginning with **User & Task Analysis**. We defined personas and validated three core functionalities: exam uploads via QR code, dependent family profile management for prescriptions, and a smart appointment agenda.

We subsequently developed **Low-Fidelity Paper Prototypes** to test interaction flows. User feedback from this stage led to redesigns of navigation menus and action button placements. These refinements were implemented in a **High-Fidelity Figma Prototype** to simulate the final visual design and interactive components, concluding with a **Heuristic Evaluation** to ensure compliance with usability standards.
