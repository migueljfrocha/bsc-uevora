# Databases

Assignments developed for the Databases course,
part of the Bachelor's Degree in Computer Science Engineering
at Universidade de Évora.

## Assignments

| Assignment | Description | Type |
|------------|-------------|------|

- Relational databases
- Entity-relationship modeling
- Normalization
- SQL queries
- PostgreSQL
