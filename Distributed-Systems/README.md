# Distributed Systems

Projects developed for the Distributed Systems course,
part of the Bachelor's Degree in Computer Science Engineering
at Universidade de Évora.

## Projects

| Project | Description | Type |
|---------|-------------|------|
| [Project&nbsp;1](./Project-1/) | Distributed apartment reservation system using a central server, PostgreSQL, TCP sockets, and Java RMI. | Practical |
| [Project&nbsp;2](./Project-2/) | Environmental monitoring system with a Spring Boot server, PostgreSQL, MQTT, gRPC, REST clients, and an admin CLI. | Practical |

## Main Technologies

- Java
- Spring Boot
- PostgreSQL
- TCP sockets
- Java RMI
- REST, gRPC, and MQTT
- Docker
