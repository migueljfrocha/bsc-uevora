# X3D Scene Construction Animation

A 3D scene animation built with **X3D** and **X3DOM**, developed for the Computer Graphics course at Universidade de Évora.

## About

This project implements a hierarchical 3D scene graph representing a natural environment. Following the assignment requirements, the scene features a distinct "construction phase" animation where the main components (Mountains, Lake, Trees, Background) originate from scattered positions and assemble together in the center to form the final landscape.

Once the scene is assembled, a secondary animation cycle begins, simulating a **Day/Night cycle** where the sun moves across the sky, dynamically changing the lighting intensity and the sky color.

## Technologies

**Logic:** JavaScript  
**Standard:** X3D   
**Library:** X3DOM

## How to Run

### Prerequisites
- Modern web browser
- Local web server

### Steps

**Start a local web server:**

```bash
npx http-server -p 8000 -o
```

**Or use VS Code Live Server:**
- Right-click on `index.html` → "Open with Live Server"

**Open in browser:**
```
http://localhost:8000 or http://localhost:5500
```
