# Three.js - 3D Custom Typography

A 3D scene rendering custom extruded text, built with Three.js and vanilla JavaScript for the Computer Graphics course at Universidade de Évora.

## About

This project implements a 3D environment featuring the word chosen by the teacher, using a serif-style font that had to be replicated. Each letter is defined using strict mathematical vector paths and Bezier curves, which are then converted into shapes and extruded into 3D meshes. The scene is completed with textured flooring, walls, and a lighting setup to enhance depth perception.

## Technologies

**Language:** JavaScript   
**Library:** Three.js

## How to Run

### Prerequisites
- Modern web browser
- Local web server

### Steps

**Start a local web server:**

```bash
npx http-server -p 8000 -o
```

**Or use VS Code Live Server:**
- Right-click on `index.html` → "Open with Live Server"

**Open in browser:**
```
http://localhost:8000 or http://localhost:5500
```
