# C2D Airplane Animation

A 2D scene graph animation featuring an airplane with a banner companion, built with vanilla JavaScript and Canvas API for the Computer Graphics course at Universidade de Évora.

## About

This project implements a 2D hierarchical scene graph animation system. The main scene features an airplane (chosen by the teacher) towing a banner (chosen as the secondary object) across a dynamic landscape, with procedurally generated clouds and birds flying in the background.

## Technologies

**Language:** JavaScript  
**Rendering:** HTML Canvas 2D Context  
**Animation Library:** Tween.js  

---

## How to Run

### Prerequisites
- Modern web browser
- Local web server    

### Steps

**Start a local web server:**

```bash
npx http-server -p 8000 -o
```

**Or use VS Code Live Server:**
- Right-click on `index.html` → "Open with Live Server"

**Open in browser:**
```
http://localhost:8000 or http://localhost:5500
```
