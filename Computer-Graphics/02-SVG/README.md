# SVG Obstacle Course Game

A 2D obstacle avoidance game featuring a boat navigating through moving obstacles, built with vanilla JavaScript and SVG for the Computer Graphics course at Universidade de Évora.

## About

This project implements a 2D obstacle avoidance game using SVG (Scalable Vector Graphics) and the DOM API. The player controls a boat (chosen by the teacher from an emoji) that must dodge falling construction workers (also chosen by the teacher) while navigating a water track.

## Technologies

**Language:** JavaScript  
**Rendering:** SVG (Scalable Vector Graphics)  

---

## How to Run

### Prerequisites
- Modern web browser
- Local web server

### Steps

**Start a local web server:**

```bash
npx http-server -p 8000 -o
```

**Or use VS Code Live Server:**
- Right-click on `index.html` → "Open with Live Server"

**Open in browser:**
```
http://localhost:8000 or http://localhost:5500
```

**Play:**
- Select speed and difficulty
- Click **START**
- Use **A** (left) and **D** (right) to move
- Avoid obstacles!
