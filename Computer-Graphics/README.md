# Computer Graphics

Projects developed for the Computer Graphics course,
part of the Bachelor's Degree in Computer Science Engineering
at Universidade de Évora.

## Projects

| Project | Description | Type |
|---------|-------------|------|
| [C2D Airplane Animation](./01-C2D/) | 2D hierarchical scene graph animation built with JavaScript and the HTML Canvas 2D API. | Practical |
| [SVG Obstacle Course Game](./02-SVG/) | 2D obstacle avoidance game built with JavaScript, SVG, and DOM interaction. | Practical |
| [Three.js Custom Typography](./03-3JS/) | 3D scene with custom extruded typography, vector paths, textures, and lighting. | Practical |
| [X3D Scene Construction Animation](./04-X3D/) | X3D/X3DOM hierarchical 3D scene with construction animation and a day/night cycle. | Practical |

## Main Technologies

- JavaScript
- HTML Canvas
- SVG
- Three.js
- X3D and X3DOM
